## 動作 prompt

Kling v3.0 / standard / 9:16 / 5 秒 / sound off。每段以同一母版作起始、結尾參考；720×1280 純洋紅背景。

待機：固定鏡頭，保持完整人設、服裝與畫幅。低頭看帳本、羽毛筆寫兩小筆、自然眨眼、抬頭微笑。雙腳固定在參考坐標，少量頭髮與衣袖跟隨動作；不得浮動、滑動、縮放、轉鏡、加物件或改變背景。五秒首尾回到相同姿勢。

招呼：固定鏡頭，小幅點頭預備，羽毛筆手舉到臉旁招呼，露出開心眼神，再放下手回到起始姿勢。另一手始終拿帳本，腳底固定，完整保留帽子、手和靴子的畫面範圍。沒有跳躍、背景陰影、文字或特效。

## 轉檔與使用

`scripts/prepare-character-motion.sh INPUT.mp4 OUTPUT-idle.webp 0` 產生循环待機及同畫布首幀；最後參數 1 產生單次招呼。需 ffmpeg、libwebp 的 img2webp/cwebp。固定裁成 720×960，再縮為 360×480，去洋紅背景與半透明邊緣溢色，10 fps 共 50 幀，品質 78。前端使用真正 alpha WebP，不使用影片、multiply 或整張 CSS 漂浮。

四段正式檔案約 1.06–1.19 MB。逐幀以 alpha >128 的可見底邊檢查：薄荷待機 435、招呼 433–435；晚星待機 436、招呼 435–436（480 高畫布）。降低動態顯示同畫布首幀；背景分頁暫停顯示動畫；動畫尚未載入時保留靜態首幀，載入後隱藏首幀避免重影。

衣服新增流程：先更新 `storybookCatalog.js` 的取得規則 → 引用母版生成衣服 → 兩段動作 → 同畫布去背與腳底 QA → `storybookAssets.js` 註冊 → 首頁、造型、小店、討伐、手帳共用 StorybookActor。髮型或大幅頭部配件會影響動作時，需補齊相容組合，不能沿用未對位的覆蓋層。
