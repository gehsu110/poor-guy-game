## 新母版先驗證的實物

1. **身體與服裝**：同一正面姿勢，頭、前後髮、軀幹、前後披風、左右手臂／手型、腿與鞋分層；袖口與手掌互相覆蓋，手不可畫死在衣服上。
2. **兩款髮型與一頂帽子**：實際四種組合使用同一臉和帽子資產。不能再為各種組合另畫完整頭圖。
3. **空手與握書**：手型從同一腕部支點整件替換；書的前後遮擋可與握手配件一起製作，不保留原手指。衣服與人物檔不因換書而重製。
4. **兩套服裝與男女**：先在共同畫布驗證交叉搭配、手機尺寸和放大；必要的身形適配有明確資料，不能把「相同商品權益」誤當「同一衣服圖必然適合男女」。
5. **共同動作**：呼吸、眨眼、披風、點按招呼沿父子支點動作；書隨手腕，帽飾隨頭，取下物品仍保持完整人物。通過這個小樣才開始大量收藏品。
