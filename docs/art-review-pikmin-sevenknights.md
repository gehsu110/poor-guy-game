# 畫風複核：皮克敏與七騎士參考

日期：2026-09-06。使用者否決 `3044446` 中的星風 3D 人物與實際造型頁。這份記錄為參考分析與修改建議，**不是已確認的新美術方向，也不是新成品**。七騎士版本仍待使用者釐清。

## 現有成品的問題

1. 人物臉部、髮束與衣料紋理混濁。精美概念圖轉為自動建模後品質下滑，模型檢查沒有攔下差距；增加骨架和旋轉功能不會改善這個問題。
2. 細長人物、褐色繪畫背景與厚重金框介面使用不同的細節密度。明暗、比例和材質沒有形成同一個世界。
3. 預設站姿僵硬，抬手動作只能證明骨架可動。角色缺少眼神、表情、重心和有目的的動作。
4. 畫面主要行為仍是瀏覽商品、查看價格、站上展示台，缺乏夥伴自主行動和可探索的生活感。

## 參考拆解

- [Pikmin Bloom 官方介紹](https://pikminbloom.com/zh_hant)：種植、散步、餵養、探險與飾品收藏構成日常循環。可借鏡的是清楚輪廓、不同外觀的辨識度、夥伴的行為與完成一組收藏的目標。套入本專案時，日常輸入改為真實記帳／零消費確認；不要求走路定位，也不以消費金額換稀有度。
- [七騎士 RE:BIRTH 官方](https://sena.netmarble.com/en)：角色設計、幻想服飾、隊伍與戰鬥演出是系列的重要呈現。官方人物設計稿與實機模型需分開檢查，不能再以宣傳圖推定模型品質。
- [七騎士放置冒險官方介紹](https://skidle.netmarble.com/en/game)：官方明確以可愛角色、隊伍組合、服裝與寵物呈現收藏和成長；與 RE:BIRTH 的比例、細節和演出方向不同。

## 建議的下一個驗收單位

先做一個完整小場景的可審視畫面：同一角色的自然站姿、一個有動作的小夥伴、可辨認的服裝／配件變化、精簡任務與記帳入口。人物與 UI 都以手機實際顯示尺寸驗收；不能只驗收孤立的角色大圖。

角色輪廓、材質、臉部和實機姿態應先通過，再擴充換裝、地圖與收藏數量。候選方向可為明亮的風格化角色與小型生活場景；人物是否採 Q 版、具體頭身比例，以及七騎士哪一版的演出方式，仍待使用者釐清。
