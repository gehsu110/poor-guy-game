# 星頁旅程實作與畫風修正 · 2026-09-06

本次採用新記帳／旅程架構，但使用者否決了實作中的簡化 SVG 畫風。可玩畫面已恢復 `storybook-v2` 手繪母版，不能將分層程式原型宣稱為已完成的正式換裝系統。

## 已接入可玩流程

- 五入口：首頁、冒險、記帳、手帳、收藏。全域記帳面板可保留未送出的草稿，成功後可返回原頁；手帳有固定文字入口。
- 帳本統一支出、收入與移轉；支援修改、刪除標記、歷史補登、月曆與明細。金額以最小貨幣單位計算；日期統一 Asia/Taipei。
- 當日首次記錄或確認零消費取得 2 黃星、15 EXP 與一次旅程；選擇回顧另給 1 黃星、5 EXP。每週累積 5 個記錄日加 5 黃星、1 紫星、50 EXP。已領不因改帳重發；不按消費金額或拆單增加獎勵。
- 3 章、15 個永久節點；最多保留 3 個待出發日期。施法每次 40 星光，夥伴技能 55；快速完成獎勵相同。中途狀態持久保存，完成取得 30 EXP、旅程印記，每章結束 1 紫星。
- 首頁、試衣預覽、戰鬥使用相同手繪套裝素材；首頁與試衣提供待機寫帳、點擊招呼。戰鬥分開背景、角色、精靈、光效、狀態和輸入，有發射、命中與數字回饋。
- 目前正式展示 2 套裝與 2 夥伴。晚星制服沿用既有 12 黃星價格；已購舊版同款與小鴞辨識為已擁有，不再次扣款。其他原型物件保留資料但未開放兌換，既有收藏不刪除。
- 圖鑑能查看旅程印記，套裝可試穿、加入心願、兌換與裝備；舊造型與票券有專屬入口。舊商店每日補給不再疊加新日常獎勵。
- 減少動態偏好停用場景粒子與特效；角色切成同母版靜態圖。短螢幕使用較緊密的 HUD 與舞台，主操作不再被擠到畫面下方。

## 存檔與開發環境

- `src/game` 分出帳本、旅程、收藏、備份與時區；`gameRepository` 統一本機与 Firestore 入口。
- 舊存檔遷移前留備份；舊公會流水匯入帳本，缺少計數的歷史日依實際明細重建。新操作的記錄、摘要與獎勵在同一交易提交。
- 本機寫入有跨分頁鎖；Firestore 交易從新鮮資料計算，編輯與戰鬥检查 revision／turn，重複送出不重复扣款或給獎。
- 備份匯入保留現有明細，只補缺少 ID；分批交易可重試。進度與收藏合併，錢包首次跨來源取較大值而非相加；再匯入同來源不恢復已花掉的星幣。
- 新增 Firestore 擁有者權限與非負數值規則、模擬器測試、Firebase／Java CI 步驟與鎖定依賴。這不是受信任伺服器上的權威經濟，不能聲稱完整反作弊。
- `?local=1` 只在開發環境強制使用本機測試存檔。設定頁清楚顯示存檔位置；雲端送出失敗不顯示已儲存。

## 驗證

- `npm run check`：ESLint、40 個領域／本機測試、production build。
- `npm run test:cloud`：8 個 Firestore 模擬器整合測試，涵蓋權限、同時新增、重送、移動日期、交易失敗、遷移、旅程結算、分批匯入與舊摘要修復。
- 實際瀏覽器檢查 390×844 首頁／戰鬥／收藏，320×568 戰鬥，套裝預覽、施法星光與進度保存。這不等於 iPhone Safari / standalone PWA 真機驗收。

## 尚未完成，不能作為正式發布宣稱

1. 正式手繪分層部件。SVG 原型已有槽位與共用动作，但畫風被否決，未在正式路由載入；目前兩套角色仍是成套演出。髮型、帽飾、上下身獨立混搭的美術驗收仍未完成。
2. 三章專屬背景、差異化事件與路線獎勵。現在已有永久進度與兩種印記，場景先共用符合品質的庭院，不能稱為三個完整世界。
3. 完整 7／30／90 日收藏節奏、更多可用物件、章節後續內容。未提供尚無實際效果的商品兌換。
4. 正式 Firebase 規則發布、Google 綁定跨裝置驗收、Cloudflare 預覽與實機 PWA 驗收。本次僅在既有 Git 工作分支保存；未合入 main 或部署正式站。

本次修正建立了可玩底層和美術品質基準，不代表全面重製已完成。後續先做好一套有收藏吸引力的手繪角色分層母版，再擴充商品與地圖。
