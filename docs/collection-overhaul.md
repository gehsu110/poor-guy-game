# 收藏冒險改版 · 2026-09-06

## 專案盤點

React 19 / Vite 8 / Firebase / Framer Motion / PWA，GitHub main 連接 Cloudflare Pages，build 輸出目錄為 build。原本的重點缺口：

| 原有情況 | 本次處理 |
| --- | --- |
| 多個角色、場景與怪物批次混用 | 建立「薄荷帳本」母版：兩件衣服、日光庭院、書頁小鴞、八種怪物；新舊系列分區 |
| 角色多為靜態或 CSS 漂移 | 四段真實透明 WebP 動畫：兩件衣服各有待機寫帳、招呼 |
| 每日目標與收藏來源不清楚 | 三件每日任務、手帳禮、自然週任務、累積日里程碑與圖鑑 |
| 支出分成多筆能增加傷害，低支出需要湊筆數 | 傷害依預算區間積分；一筆如實紀錄即可獲得好評價；零消費也可完成 |
| 修改或刪除支出後怪物狀態不一致 | 用有效支出重算戰鬥，紀錄與每日快照一起提交 |
| 本機模式不持久、雲端失敗容易卡載入 | 持久本機存檔、讀寫失敗訊息、載入期限、匯出 JSON、跨分頁同步 |
| 任務與商店採先改畫面再寫資料 | 主要獎勵、支出、商店兌換使用交易，檢查版本、餘額與領取標記 |
| S 評價不給黃星、商品有尚未可用內容 | 統一日常黃星來源，紫星轉為週成長來源；可兌換列表隱藏未實作商品 |
| PWA 首次預先快取約 67 MB，更新立即接管 | 僅預先快取核心內容，其他美術按使用快取；更新提示不在記帳時強制重載 |

## 可玩的收藏循環

如實記帳或確認零消費 → 看遠征地圖 → 確認帳本 → 領每日手帳禮。週任務固定週一至週日；月度路線使用「遠征區」名稱。累積里程碑保留中斷前的進度，補登只修正帳本，不用來刷遊戲獎勵。守住預算的最後一擊在跨日結算。

薄荷帳本系列有兩件衣服：免費薄荷學徒裝、12 黃星兌換晚星制服。書頁小鴞是累積記帳 3 天的專屬收藏。衣服與夥伴獨立保存，換衣不會卸下夥伴。經典系列原有九槽混搭和三套預設仍保留。

新系列本次提供衣服及夥伴分槽；新髮型、帽子、眼鏡、背飾尚未製作完整動畫組合。擴充必須沿用母版與固定畫布，不能直接將舊風格配件疊在新角色上。

## 貨幣規則

- 黃星：每日結算 S/A 2、B/C 1；每日手帳禮 2；商店每日補給 1。週任務及里程碑另有獎勵。
- 紫星：自然週累積記帳 5 天、7 天各 1；部分成就和遠征另有獎勵。
- 一般券、金券：保留原有餘額與補給功能。常駐池目前只放已接上效果的稱號、頭像框；金池使用相同收藏池，機率為普通 55%、稀有 33%、傳說 12%。重複收藏補償依稀有度發星星。
- 一般配件約 6–18 黃星、晚星制服 12 黃星；新價格不扣除原有餘額或收回既有收藏。商店直接顯示來源與相容系列。

## 驗證與部署

`npm run check` 執行 ESLint、Node 行為測試與正式建置。測試涵蓋金額格式、拆單傷害、跨日結算、自然週、零消費、補登限制、獎勵重複領取、存檔失敗、交易版本、重複兌換與衣服／夥伴獨立保存。CI 固定 Node 22。

瀏覽器使用本機「測試冒險者」存檔驗證，包含新增、修改、重新整理、跨午夜結算、每日手帳領獎、造型預覽、餘額不足與手機排版。正式 Firebase Google 綁定、跨裝置同步與已安裝 iOS PWA 的更新流程，仍需在對應環境驗證；本次本機檢查不等同於已通過這些環境。

Cloudflare Pages 保持 main / `npm run build` / `build`，需在專案環境設定對應 VITE_FIREBASE_*。新的驗證分支不代表已切換正式站。工作開始前已有未提交的套裝、美術文件及 build 產物；本次 Git 提交應排除那些原有變更。
