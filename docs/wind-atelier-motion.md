# 手帳固定與衣料待機

2026-09-06。使用者指出書本像貼在手下、衣服失去動作。本次保留目前人物，處理實際配戴與可見衣料擺動。

## 已實作

- 書本改為有棕色扣帶與金屬鉚釘的腰掛手帳，保留深藍封面與羅盤金飾。男女、薄荷與晚星各有腰部定位；不再套用扶腰手掌遮擋。它是掛在側腰的隨身物，不宣稱角色已具備握書手型。
- 身體、已選頭部、帽飾與配件先在執行時組裝成同一張透明貼圖，再用 2D 網格播放輕呼吸、小幅頭部動作、薄荷披風及晚星衣襬擺動。眨眼使用原有眼部素材。沒有啟用舊生成全身影片。
- 鬆動衣料的範圍與擺幅集中在 `src/character/clothMotion.js`。新的套裝只增加該套服裝的範圍資料；不為不同頭髮、帽子、書本再生成整段影片。
- 手帳周圍的網格採同一個腰部位移，不隨裙襬彎曲。腳底沒有呼吸或衣料權重；衣料變形不作用於臉部。
- 靜態 SVG 與動畫貼圖共用同一套素材、座標、頭部裁切和道具定位。動畫第一幀完成才切換；不支援 WebGL、編譯失敗或 context 遺失會回到完整 SVG。裝備資料與記帳流程不依賴 WebGL。
- 畫面以 30 fps 為上限，合成貼圖最高 2048 像素高；顯示解析度限制像素比與高度。換裝、卸載時取消更新並釋放 GPU 資源。細節面板開啟會暫停後面的主角；近看、記帳面板、減少動態、省流量與背景分頁沿用靜態流程。

## 美術來源

`belt-journal.webp` 由既有 `book.webp` 編輯，使用內建 imagegen。原始輸出沒有真正透明通道，因此另用 Higgsfield `image_background_remover`（工作 `4fff5a21-0f5c-45d3-a881-0aced0d82e93`）取得 alpha，依透明邊界裁切並匯出 392 × 600 WebP。

製作提示與來源見 [提示紀錄](./wind-atelier-motion-prompts.json)。既有書本原稿保留；程式只引用已提交的新素材，不依賴生成工具或暫存目錄。

## 邊界

這是現有立繪的受控 2D 動作，不是完整行走、揮手、翻書或戰鬥骨架。現有髮型與帽飾仍是預製整頭變體；新母版的獨立分件門檻仍依 [人物擴充規格](./character-extensibility.md)。旅行包仍沿用既有手部適配，此次更正的是手帳，不把它描述成所有手持物已完成。

## 驗證

- 實機檢查男女、薄荷／晚星、手帳開關與帽飾切換；比較衣襬不同時刻，檢查腳底、頭頸、衣料接合與重影。
- 程式測試涵蓋衣料活動範圍、腳與臉部的排除、網格索引、手帳剛性，以及 WebGL 缺失／編譯失敗的 SVG 回退。
- 所有試穿都不購買商品、不新增帳目；完成後回復原本已裝備的造型。

實機驗證包含原生 637 × 784 與 390 × 844。近看與記帳面板時動畫 canvas 數量為 0；減少動態開啟後為完整靜態造型，關閉後恢復。測試後已解除臨時 viewport 並還原原始女生／薄荷／短髮／貝雷帽／手帳和原本的動態設定。
