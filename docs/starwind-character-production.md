## 實際處理

- 縫合相同位置的頂點法線，改善臉部接縫的三角塊感；校正原模型過高的金屬與自發光參數，衣料維持霧面。
- 保留待機的手臂動作，減弱頭頸、軀幹旋轉；去除動作檔額外縮放、位移與腿部屈膝，維持角色腳底落點。招呼是共用的短手臂動作，不是影片或整張人物漂浮。
- 人物紋理縮為 1536 px、配件 768 px，封裝 EXT_texture_webp。六個 GLB 從 47.85 MB 降為 8.57 MB；每次只讀取目前套裝與裝備，非一次載入全套。
- 人物引擎獨立延遲載入；小圖、頭像、啟動頁使用實際渲染截圖，不建立 WebGL 畫布。收藏小圖展示商品本體。
- 造型間可拖曳／按鈕旋轉，另有全螢幕全身／近看模式；開啟細節時釋放外層人物。小螢幕保留底部收藏列，寬視窗改並排。
- WebGL 不可用時顯示同套裝靜態圖與載入錯誤，記帳介面仍可操作。靜態圖只代表基礎套裝，不把配件顯示成功當作保證。
- 背景分頁、不可見畫布停止繪製；減少動態會停止自動動作。卸載釋放模型、紋理、骨架與 WebGL context；GLB 經 Service Worker 按需快取。

## 驗收

- 真實瀏覽器確認兩套衣服正面與臉部、配件單獨顯示、旋轉側面／背面、全螢幕細節、招呼、手機 390×844 與原視窗。
- 本機實際裝備免費緞帶、取下隨身物、重整核對保存；新旅行包僅試穿，未花使用者貨幣。修正空配件重整時的載入錯誤。
- 所有權、套裝／配件保留、空槽重整、兌換重試等 Node 測試；Firestore emulator 驗證同配件同時購買只扣款一次、保存空槽、帳目不變。
- 髮絲物理、眨眼、布料模擬與行走／戰鬥專屬動作尚未製作。這批集中在人物品質與實際換裝，不啟用先前被否決的大原野。

最終檢查：`npm run check`（lint、56 個 Node 測試、正式建置）及 `npm run test:cloud`（11 個 Firestore emulator 測試）通過。使用者本機仍為黃星 6、紫星 1、支出 80、餘額 420；測試後還原原本的貝雷帽、手帳與動態設定。
